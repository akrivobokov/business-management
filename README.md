# На пикселе

Django-проект для продажи рекламных пикселей на общем поле 3840×21600.

## Что реализовано
- Светлый современный лендинг в мультиколор-стиле.
- Поле продажи: **3840×21600 пикселей**.
- Минимальная ячейка: **10×10 пикселей**.
- Тарифы:
  - 1–20 ячеек: 5000 ₽/ячейка
  - 21–50 ячеек: 3000 ₽/ячейка
  - от 51 ячейки: 1500 ₽/ячейка
- Кнопка **«Рандомный сайт»** с модальным окном, переходом по баннеру и переключением «следующий/предыдущий».
- Кнопка **«Хочу быть на пикселе»** с формой заявки:
  - выбор физлицо / юрлицо(ИП)
  - обязательное согласие на обработку ПДн
  - активация кнопки «Приобрести» только при заполнении обязательных полей
- Отправка заявки в Telegram-группу (при заданных переменных окружения).
- После заявки:
  - физлицо: выбор ЮMoney или СБП
  - юрлицо/ИП: генерация счёта с нумерацией НП00001, НП00002...
- Админ-панель для управления баннерами, заявками и счётами.

## API
- `POST /api/pixel-order/` — создание заявки на размещение.

## Настройка Telegram
Укажите переменные окружения:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_GROUP_CHAT_ID`

## Запуск
```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
